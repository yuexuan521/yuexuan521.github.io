MT1080 乘积之和#

（1）题目 给定一个正整数n，求满足floor（n/x）=y的x和y的乘积之和 (x和y是正整数)。比如输入5，则(x, y)的组合可以有:(1, 5), (2, 2), (3, 1), (4, 1), (5, 1)，那么， 1 * 5 + 2 * 2 + 3 * 1 + 4 * 1 + 5 * 1 = 5 + 4 + 3 + 4 + 5 = 21。不考虑负数，0或者其他特殊情况。

格式

1
2

输入格式：
输入为整型

输出格式：
输出为整型

样例1

1
2

5

#include<stdio.h>
int main() 
{ 
    int n, y = 0, sum = 0;
    scanf("%d", &n);
    for (int x=1;x<=n;x++)
    {
        y = n / x;
        sum += x * y;
    }
    printf("%d\n", sum);
    return 0;
