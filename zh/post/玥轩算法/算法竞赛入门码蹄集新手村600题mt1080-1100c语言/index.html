（1）题目 给定一个正整数n，求满足floor（n/x）=y的x和y的和。不考虑负数，0或者其他特殊情况。比如输入5，则(x, y)的组合可以有:(1, 5), (2, 2), (3, 1), (4, 1), (5, 1)，那么， 1 + 5 + 2 + 2 + 3 + 1 + 4 + 1 + 5 + 1 = 6 + 4 + 4 + 5 + 6 = 25。

MT1085 分期付款#

（1）题目 请编写一个简单程序，使用以下公式计算每月分期付款：

其中： p=本金 r=每月利率 n=分期付款多少个月

#include<stdio.h>
#include<math.h>
int main() 
{ 
    double p, r, n, EMI, R;
    scanf("%lf %lf %lf", &p, &R, &n);
    r = R / (12 * 100);
    EMI = p * r * pow(1+r, n) / (pow(1+r, n) - 1);
    printf("%.1lf", EMI);
    return 0; 
}
