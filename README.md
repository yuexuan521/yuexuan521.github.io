## 📖 简介 | Introduction

> **"The days are long but the decades are short."**
> <br>

本项目基于 **Hugo** 静态网站生成器构建，采用了简约优雅的 **PaperMod** 主题，并通过 **GitHub Actions** 自动部署。

## 🚀 本地运行 | Run Locally

如果你想在本地查看本博客的效果，或者基于此修改代码，请按照以下步骤操作：

### 1. 环境准备
确保你已经安装了 [Git](https://git-scm.com/) 和 [Hugo Extended](https://gohugo.io/installation/) 版本。

### 2. 克隆仓库
注意：由于使用了 PaperMod 主题作为子模块，需要使用 `--recursive` 参数。

```bash
git clone --recursive [https://github.com/yuexuan521/yuexuan521.github.io.git](https://github.com/yuexuan521/yuexuan521.github.io.git)
cd yuexuan521.github.io
```

### 3. 启动服务

运行以下命令启动本地服务器：

Bash

```
hugo server -D
```

*注：`-D` 参数用于包含草稿 (Drafts) 内容。*

打开浏览器访问 `http://localhost:1313` 即可预览。
