### 解题思路：

1、尝试flag2.zip无果。在查看flag3.zip时，找到关于密码的提示“呀！我把压缩包密码忘记了，依稀记得是6位数字”。

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209931.png)

使用工具Ziperello爆破密码，选定参数使用六位纯数字，破解得到密码183792。

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209932.png)

使用密码解压flag3.zip压缩包，得到两个文件。

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209933.png)

2、查看flag.docx文件，内容如下。根据同一文件的mp4文件，猜测提示为视频时间5.20和7.11。

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209934.png)

查看视频，在视频时间5.20和7.11附近，找到了两段提示字符，分别如下两图。

敲击码，手工解密。

```bash
敲击码（由两个数字定位一个字母，使用“/”进行字母间的分隔。）
密文：..... ../... ./... ./... ../
     5     2 /3   1/3   1/3   2 /
明文：   W       L     L     M     
```

![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209935.png)

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209936.png)

Base64编码，使用在线网站进行解密。 [BASE64加密解密](https://base64.supfree.net/) 

```bash
Base64编码
密文：dXBfdXBfdXA=
明文：up_up_up
```

![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209937.png)

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209938.png)

组合起来，全部小写作为flag2.zip文件的解压密码。

```bash
wllmup_up_up
```

3、解压flag2.zip文件，得到一张Real flag.jpg的图片，使用010 Editor打开，翻到最后，找到flag。

 ![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209939.png)
