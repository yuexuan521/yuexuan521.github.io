### 密文：

下载附件，解压得到两个zip压缩包。
 ![两个压缩包：flag2.zip（6 KB）与 flag3.zip（16,317 KB）](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209930.png)

### 解题思路：

1、尝试flag2.zip无果。在查看flag3.zip时，找到关于密码的提示“呀！我把压缩包密码忘记了，依稀记得是6位数字”。

 ![Bandizip 打开 flag3.zip，里面是 flag.docx 与 影流之主.mp4，底部提示「呀！我把压缩包密码忘记了，依稀记得是6位数字」](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209931.png)

使用工具Ziperello爆破密码，选定参数使用六位纯数字，破解得到密码183792。

 ![Ziperello 破解：当前密码长度 6，弹窗给出「密码：183792」](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209932.png)

使用密码解压flag3.zip压缩包，得到两个文件。

 ![解出 flag.docx（18 KB）与 影流之主.mp4（16,299 KB）](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209933.png)

2、查看flag.docx文件，内容如下。根据同一文件的mp4文件，猜测提示为视频时间5.20和7.11。

 ![Word 里是一句话「从小 5 就 20 列文虎克，我每年的 7 月 11 日的生日愿望就是拥有一个🔍」加列文虎克画像](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209934.png)

查看视频，在视频时间5.20和7.11附近，找到了两段提示字符，分别如下两图。

敲击码，手工解密。

```bash
敲击码（由两个数字定位一个字母，使用“/”进行字母间的分隔。）
密文：..... ../... ./... ./... ../
     5     2 /3   1/3   1/3   2 /
明文：   W       L     L     M     
```

![视频里吊灯画面上隐约浮着一行白字](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209935.png)

 ![查资料：敲击码用 5×5 波利比奥斯方阵、K 并入 C，(.. | .) 即 2,1 得 F](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209936.png)

Base64编码，使用在线网站进行解密。 [BASE64加密解密](https://base64.supfree.net/) 

```bash
Base64编码
密文：dXBfdXBfdXA=
明文：up_up_up
```

![放大后看清那行字是 dXBfZFfXbfdXA=](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209937.png)

 ![Base64 工具里输入 up_up_up，点「BASE64加密 / 解密」](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209938.png)

组合起来，全部小写作为flag2.zip文件的解压密码。

```bash
wllmup_up_up
```

3、解压flag2.zip文件，得到一张Real flag.jpg的图片，使用010 Editor打开，翻到最后，找到flag。

 ![十六进制里大片 0A 之间夹着 73 77 70 75 63 74 66 7B…，解出 swupctf{A2e_Y0u_Ok?}](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251223165209939.png)

### flag：

```bash
flag{A2e_Y0u_Ok?}
```
