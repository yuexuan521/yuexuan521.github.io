### MT1160 尾数为0

***（1）题目*** 
输入正整数N，请在1!，2! ， 3! …N!中查找尾数为零的数，统计这样的数字的个数并输出。

---

**格式** 

```
输入格式: 
输入正整数N

输出格式:
输出整型
```

**样例1** 

```
输入格式: 
5

输出格式: 
1
```

***（2）参考代码*** 

```c
#include<stdio.h>
int main() 
{ 
    int N, factorial, count = 0;
    scanf("%d", &N);
    for (int i=1;i<=N;i++)
    {
        factorial = 1;
        for (int j=1;j<=i;j++)
        {
            factorial *= j;
        }
        if (factorial % 10 == 0)
        {
            count++;
        }
    }
    printf("%d", count);
    return 0; 
}
```
