```c
{ 
    int a, b, n1, n2;

        num += (1.0 / (double)i);
```

---

**格式** 

```
输入格式：
无


输出格式：
输出为实型，保留2位小数
```

**样例1** 

```
输入：
无

输出：

```

***（2）参考代码*** 

```c
#include<stdio.h>
int main()
{
    double x = 0, PI = 0;
    for (int i = 1;;i += 2)
    {
        x = 1 / (double)i;
        if (x < 1e-6)
        {
            break;
        }
        if (i % 4 == 3)
        {
            x = -x;
        }
        PI += x;
    }
    printf("%.2lf\n", 4 * PI);
    return 0;
}
```
