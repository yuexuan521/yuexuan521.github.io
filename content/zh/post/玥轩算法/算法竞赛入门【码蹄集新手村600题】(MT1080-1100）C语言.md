### MT1081 x+y的和

***（1）题目*** 
给定一个正整数n，求满足floor（n/x）=y的x和y的和。不考虑负数，0或者其他特殊情况。比如输入5，则(x, y)的组合可以有:(1, 5), (2, 2), (3, 1), (4, 1), (5, 1)，那么， 1 + 5 + 2 + 2 + 3 + 1 + 4 + 1 + 5 + 1 = 6 + 4 + 4 + 5 + 6 = 25。

---

**格式** 

```
输入格式：
输入为整型


输出格式：
输出为整型
```

**样例1** 

```
输入：
5

输出：
25
```

***（2）参考代码*** 

```c
#include<stdio.h>
int main() 
{ 
    int n, x, y, sum = 0;
    scanf("%d", &n);
    for (x=1;x<=n;x++)
    {
        y = n / x;
        sum += x + y;
    }
    printf("%d\n", sum);
    return 0; 
}
```

![在这里插入图片描述](https://cdn.jsdelivr.net/gh/yuexuan521/image/20251220162318004.png)

其中：
p=本金
r=每月利率
n=分期付款多少个月

如果年利率为R%，则使用以下公式计算月利率：
Rate ® = R/(12*100)

---

**格式** 

```
输入格式：
输入本金、年利率、多少个月，double型，空格分隔


输出格式：
输出double型，保留1位小数
```

**样例1** 

```
输入：
1000000 7 120

11610.8
```

***（2）参考代码*** 

```c
#include<stdio.h>
#include<math.h>
int main() 
{ 
    double p, r, n, EMI, R;
    scanf("%lf %lf %lf", &p, &R, &n);
    r = R / (12 * 100);
    EMI = p * r * pow(1+r, n) / (pow(1+r, n) - 1);
    printf("%.1lf", EMI);
    return 0; 
}
```
